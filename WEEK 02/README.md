# Week 2 – Enterprise Infrastructure Planning for a Startup Company

# Project Overview
Every successful IT infrastructure begins with proper planning. Before purchasing computers, installing servers, configuring networks, or deploying cloud services, a System Administrator must first understand the organization's business requirements and design an infrastructure that supports business operations.
In this project, I assumed the role of a Junior System Administrator assigned to prepare the initial IT Infrastructure Plan for a newly established startup company, ABC Startup Solutions. The output represents a professional enterprise document detailing hardware, software, network topology, administrative roles, and security recommendations.

# Company Scenario
ABC Startup Solutions is a newly established software development company located on the 4th Floor, Tech Hub Building, Santa Cruz, Laguna, Philippines. The company has 20 employees occupying a single office floor.

---

# Hardware Inventory Summary
- **Workstations & Laptops:** High-powered desktop computers for the 5 developers in IT, reliable standard desktops for the 9 office staff in HR and Finance, and lightweight laptops for the 6 Sales team members who travel for client meetings.
- **Monitors:** Dual screen setups for IT, HR, and Finance to make multitasking easier, plus single monitors with quick laptop docking stations for Sales.
- **Central Infrastructure:** One main office server to run internal apps, one large storage drive (NAS) to save shared files, and two portable external hard drives for safe offsite backups.
- **Office & Power Equipment:** One shared office laser printer, plus backup batteries (UPS units) connected to the server and desktops so work isn't lost during sudden power outages.

# Software Inventory Summary
- **Operating Systems:** Windows 11 Pro for employee computers and Ubuntu Linux for the main office server.
- **Office & Communication:** Microsoft 365 for work emails, Word documents, Excel spreadsheets, and team messaging.
- **Development Tools:** VS Code, Git, and GitHub Desktop so the IT team can write, manage, and back up software code.
- **Security & Utilities:** Built-in Microsoft Defender antivirus to block malware, AnyDesk for remote IT support, Google Chrome for web browsing, and 7-Zip for sending compressed files.

# Reflection

Building the plan for the enterprise infrastructure made me realize that system administration goes way beyond inserting cables and installing software. This project taught me strategic thinking in making sure that any technological decision made is aligned with the business needs. I got to learn practically how to analyze the processes used by each department, size hardware, set up security policies including 3-2-1 backups, and design VLANs in each department to ensure that network traffic remains separated and safe.

The most challenging part of this project was designing the logical network topology on Draw.io. Making sure the system is protected enough yet still efficient enough is very complicated when it comes to isolating sensitive departments such as HR and Finance while providing connections to common resources including database servers, NAS, and printers. I learned firsthand that not thinking things through may result in costly mistakes regarding the hardware and inefficient systems.

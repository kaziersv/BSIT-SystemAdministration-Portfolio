# Reflection
Setting up a sort of structured workstation is like, an essential first step for any system administrator, honestly. During this session , I managed to install core development tools, virtualization platforms, and operating system installers— including Git, GitHub Desktop, Visual Studio Code, Oracle VM VirtualBox, and ISO images for both Ubuntu and Windows. By preparing these tools I got a pretty direct, hands-on introduction to local system configurations, hypervisors, and basic file management.

Also, making professional profiles on GitHub and LinkedIn really supports the idea of a technical identity, plus it pushes clean documentation habits in IT. Using Git together with GitHub Desktop gives me a dependable flow for recording configuration changes and project history. That part matters a lot when managing enterprise servers, or when you’re collaborating in technical settings where things have to be traceable.

Working with VirtualBox plus the Ubuntu and Windows ISO files gave me practical insights into virtualized infrastructure. I initially felt confused about ISO mounting and disk partitioning, but once it clicked, I could see how hypervisors create isolated environments on virtual disks. In other words, you don’t need physical USB drives and you also avoid messing with important host system files by accident.

From here, this virtualization setup becomes a safe sandbox where I can test operating systems, tinker with server configurations, and sharpen technical skills without disrupting my main machine. And when you combine that with version control and documentation workflows, it’s a solid base for my continuous learning as a future system administrator.
